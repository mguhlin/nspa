AI Prompting for Scholarship Review

Practice a workflow you can inspect. Use fictional applications to organize files, check intake rules, and match evidence to a rubric in ChatGPT.

What I will practice

  1. Define one task, its sources, and criteria for a useful response.
  2. Set up a ChatGPT Project with standing instructions.
  3. Run three demonstrations and verify every finding.
  4. Package a procedure as a reusable skill and test it.
  5. Keep privacy, applicant rules, and human decisions visible.

About the demonstrations

All application records, rules, excerpts, rubric anchors, and example outputs are fictional teaching material. The practice page provides copyable prompts for a live ChatGPT run and clearly labeled prepared examples for comparison. No real applicant data is needed.
