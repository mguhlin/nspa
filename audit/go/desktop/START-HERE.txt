SSAT — Scholarship Security Audit Toolkit

1. Linux: install the .deb package; Windows/Mac: extract the download.
2. Open SSAT Security Audit from your applications menu on Linux,
   SSAT.exe on Windows, or SSAT.app on Mac.
3. Choose Start New Audit, enter an audit name and your role, and follow My roadmap.
4. Start with the five questions. Not sure is a useful answer and stays an unknown.
5. Save audit creates a password-protected .ssat file. Remember the passphrase;
   there is no password reset. Reopen it with Open saved audit.

No internet, account, external browser, cloud server, or AI service is required
for the audit. All app assets and examples are included. Website links are
blocked inside the desktop app. The app uses the operating system's embedded
webview to display the shared interface in its own window.

WINDOWS (x64): Requires Windows 10/11 with WebView2 Runtime. If it is missing,
run the included MicrosoftEdgeWebView2RuntimeInstallerX64.exe first. This is
Microsoft's full offline installer, not its internet bootstrapper. Normal
publisher/organization policies still apply. Then open SSAT.exe again.
The runtime installer is publisher-verified during packaging. It has not been
qualified here on a clean physical Windows device without the runtime.

MAC (macOS 13 or newer): Choose Apple Silicon or Intel to match your Mac. Uses built-in WKWebView.
The app is an unsigned/unnotarized preview; organization or Gatekeeper policies
may prevent launch. No signing/notarization or physical Mac qualification is
claimed. Do not disable your computer's security protections.

LINUX (x64): Debian 12 / Ubuntu 22.04 or newer.
Preferred installer: ssat-desktop-linux-amd64.deb
Open it with your system's package installer, or run from its download folder:
  sudo apt install ./ssat-desktop-linux-amd64.deb
Then open SSAT Security Audit from your applications menu, or run: ssat
Remove the app with: sudo apt remove ssat-desktop
Removing the package leaves your saved audit files alone.

The package declares GTK 3, WebKitGTK 4.1, and the other required system
libraries. Your package manager may need internet to obtain missing libraries
during installation. Once installed, audit work is offline. This installer
does not bundle the entire Linux system-library dependency closure.
The portable tar.gz remains available for manual extraction and ./SSAT use.
An ordinary graphical desktop session is required.

The program is a self-assessment assistant, not certification or legal advice.
Record roles, types of information, and safe references, not applicant records,
banking details, passwords, or other sensitive source material.

Reports are ordinary unencrypted exports. Review them before sharing. To print
or make a PDF, save the printable HTML report and open it in a browser or
compatible viewer. This is the one desktop task that uses an external viewer.

Close warnings protect unsaved work; there is no automatic recovery file.
Native file picker cancellation leaves your session unchanged. Successful
writes are staged next to your chosen destination; replacement and durability
guarantees depend on your OS and filesystem. Downloads, exports, OS caches,
and backups have their own lifecycles.

Unsigned preview builds. Verify SHA256SUMS.txt from the same GitHub release.
Source: https://github.com/mguhlin/nspa/tree/main/audit
